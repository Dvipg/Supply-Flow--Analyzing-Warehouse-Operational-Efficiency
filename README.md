# Supply Flow: Analyzing Warehouse Operational Efficiency

> **Capstone Project** — Jain (Deemed-to-be University)

---

## 📌 Project Overview

**Supply Flow** is a data analytics capstone project focused on diagnosing and improving warehouse operational efficiency across the supply chain lifecycle. Using exploratory data analysis, KPI tracking, and visual dashboards, this project identifies bottlenecks, quantifies inefficiencies, and recommends actionable strategies for warehouse optimization.

---

## 🎯 Objectives

- Analyze key warehouse operational metrics (throughput, order fulfillment, inventory turnover)
- Identify bottlenecks in inbound, storage, and outbound logistics
- Visualize KPIs through interactive dashboards
- Provide data-driven recommendations to reduce operational costs and improve efficiency

## 📊 Key Areas of Analysis

- **Receiving Efficiency** — Tracking inbound lead times and unloading bottlenecks
- **Inventory Management** — Overstock/understock analysis, turnover rates
- **Order Fulfillment** — Pick-pack-ship timelines, error rates
- **Warehouse Layout** — Space utilization and slotting efficiency
- **Operational KPIs** — OTIF rate, cycle time, throughput, cost per order

## 💡 Recommendations

1. Reallocate fast-moving SKUs closer to dispatch zones to cut travel time
2. Implement cycle counting to reduce inventory discrepancies
3. Introduce threshold-based reorder alerts to prevent stockouts
4. Standardize receiving schedules to reduce congestion at dock doors
